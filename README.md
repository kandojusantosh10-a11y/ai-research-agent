# ai-research-agent
🧠 AI Research Agent

An interactive AI-powered research assistant built using Python and Streamlit. This project simulates an intelligent agent that processes user queries step-by-step—understanding the question, breaking it down, and generating structured responses.

🚀 Features
🧠 Step-by-step reasoning (Agent-style thinking)
💬 Interactive chat interface
🗂️ Chat history memory
⚙️ Sidebar with clear chat option
⚡ Lightweight & fast (no heavy model dependencies)
🎯 Beginner-friendly but impactful project

🛠️ Tech Stack
Python
Streamlit
🧠 How It Works

The AI agent follows a structured workflow:

Understanding the Query
Breaking it into smaller parts
Generating a clear and simple response

This simulates how real AI agents process and respond intelligently.

▶️ Installation & Run
pip install streamlit
streamlit run app.py
